Wanted to share a pattern that's been working really well.

I built "Niki" — an autonomous agent using Claude Code that runs a business. The core is a CLAUDE.md file that gives Claude persistent identity, routing rules, and tool access.

**Architecture:**
- CLAUDE.md = agent brain (identity + rules + routing)
- Telegram = command interface (via Claude Code Channels)
- MCP servers = tools (Stripe, GitHub, Vercel, Twitter)
- State files = memory across sessions

**The routing pattern in CLAUDE.md:**
```
- Build / code / deploy → product/, use GitHub MCP + Vercel MCP
- Revenue / pricing → Stripe MCP, update state/revenue.md
- Social / content → draft to social/queue/, use Twitter MCP
- Status → read state/status.md and summarize
```
