## What is Niki?

Niki is a done-for-you setup that turns Claude Code into an autonomous business agent. It manages code, deployments, payments, and social media — all from Telegram.

Built entirely on Anthropic's native tooling. No custom infrastructure required.

## The stack

- **Claude Code** — the agent brain
- **Telegram** — command interface (Claude Code Channels)
- **GitHub MCP** — code and repos
- **Vercel MCP** — deployments
- **Stripe MCP** — payments
- **Twitter MCP** — social media
