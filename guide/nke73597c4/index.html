1

Open your Terminal (command prompt)

~2 min
🤔 What is a Terminal?
A Terminal (also called Command Prompt) is a text-based way to control your computer. Instead of clicking icons, you type commands. It sounds scary but you'll only be copying and pasting things from this guide.
How to open it:

Press the Windows key on your keyboard, type cmd, then press Enter. A black window will open — that's your terminal.

Press Cmd + Space, type Terminal, then press Enter. A white or black window will open — that's your terminal.

✅ You'll know it worked when
You see a blinking cursor and some text like C:\Users\YourName> (Windows) or yourname@computer ~ % (Mac). That means it's ready for you to type.
2

Install Node.js

~5 min
🤔 What is Node.js?
Node.js is software that lets your computer run certain tools — including Claude Code. Think of it like installing a required app. You only do this once.
1. Go to nodejs.org and download the LTS version

Click the big green button that says "LTS". Run the installer and click Next through all the steps.

2. Verify it installed correctly

In your terminal, copy and paste this, then press Enter:

node --version
✅ You'll know it worked when
You see something like v20.11.0 (the number doesn't have to match exactly).
⚠️ If you see "not recognized" or "command not found"
Close the terminal window, open a new one, and try again. If it still doesn't work, restart your computer then try again.
3

Install Claude Code

~3 min
🤔 What is Claude Code?
Claude Code is Anthropic's official tool for running AI agents on your computer. It's what makes Niki work. You install it once and it connects to your Claude account.
1. Install Claude Code

Copy and paste this into your terminal, then press Enter:

npm install -g @anthropic-ai/claude-code

You'll see a lot of text scroll by — that's normal. Wait for it to stop and show your cursor again (about 30 seconds).

2. Log in to your Claude account

Type this and press Enter:

claude

A browser window will open. Log in with the same email you use for Claude.ai. Come back to the terminal when done.

✅ You'll know it worked when
The terminal shows a > prompt and you can type to Claude. Type hello and press Enter to test it.
4

Create your agent's home folder

~2 min

Your agent needs a dedicated folder on your computer. All its files, memory, and drafts live here.

1. Create the folder structure

Copy and paste this entire block into your terminal, then press Enter:

mkdir my-agent && cd my-agent && mkdir state && mkdir docs && mkdir product && mkdir social\queue && mkdir social\posted
mkdir my-agent && cd my-agent && mkdir -p state social/queue social/posted docs product
2. Create the CLAUDE.md file

This is the brain of your agent — it tells Claude who it is and what to do. Open the folder on your computer (it's called my-agent in your home folder), create a new file called exactly CLAUDE.md, and paste the template from Part 6 below.

5

Connect Telegram

~8 min
🤔 Why Telegram?
Telegram is how you send commands to your agent from anywhere — your phone, tablet, or another computer. Instead of sitting at your computer typing, you can message your agent like you'd message a friend.
  • Open Telegram on your phone or computer
  • Search for @BotFather and open that chat
  • Send the message: /newbot
  • Give your bot a name (e.g. "My Agent") and a username ending in _bot
  • Copy the token BotFather sends you (looks like: 1234567890:ABCdefGhi...)
Install the Telegram plugin in Claude Code

In your terminal, make sure you're in the my-agent folder, then run:

claude plugin install plugin:telegram:telegram
Configure with your bot token

Start Claude Code, then type:

/telegram:configure

Paste the token from BotFather when asked.

Pair your account

Message your new bot "hello" on Telegram. Then in Claude Code, type /telegram:access and approve the pairing request.

✅ Test it
Send "status" to your bot. It should reply. If it does — you're connected!
6

Connect your tools

~15 min
🤔 What are MCP tools?
MCP tools are like apps your agent can use. GitHub MCP lets it manage your code. Stripe MCP lets it handle payments. Each one takes about 3 minutes to set up.
GitHub — code & deployments
  • Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
  • Click "Generate new token (classic)" → tick the "repo" checkbox → Generate
  • Copy the token (starts with ghp_) — you won't see it again
claude mcp add github-mcp npx -- -y @modelcontextprotocol/server-github
export GITHUB_PERSONAL_ACCESS_TOKEN=paste_your_token_here
Stripe — payments
  • Log in at dashboard.stripe.com → Developers → API keys
  • Copy the "Secret key" (starts with sk_live_ or sk_test_)
claude mcp add stripe npx -- -y @stripe/agent-toolkit
export STRIPE_SECRET_KEY=paste_your_key_here
Vercel — website deployments
  • Log in at vercel.com → Settings → Tokens → Create token
  • Copy the token
claude mcp add vercel-mcp npx -- -y @vercel/mcp-adapter
export VERCEL_TOKEN=paste_your_token_here
7

Launch your agent

~2 min
Start Claude Code in your project folder
cd my-agent claude
Send your first command via Telegram

Open Telegram, message your bot:

status

Your agent will reply with a summary of where things stand.

🎉 You're live
Your AI agent is running. Try asking it to "create a Stripe product called Test for $1" or "draft a tweet about my project."

# Agent Identity You are **[Your Agent Name]** — an autonomous AI business agent built on Claude Code. Twitter/X handle: [@yourhandle] --- # Rules of Engagement - Never spend money or delete data without confirmation via Telegram - Never share API keys or credentials in any file - Never post to social media without review in social/queue/ first - Always update state/status.md after completing any task - Keep responses short — owner reads via Telegram --- # Channel Routing - Build / code / deploy → product/, use GitHub + Vercel MCP - Revenue / payments → Stripe MCP, update state/revenue.md - Social / content → draft to social/queue/, use Twitter MCP - Status → read state/status.md and summarize - Questions → answer directly, save findings to docs/ --- # Active Project **Product:** [Your product name] **Pricing:** [Your price] **Target customer:** [Who is this for] --- # Tech Stack - Claude Code + Channels (Telegram interface) - GitHub MCP — code and repos - Vercel MCP — deployments - Stripe MCP — payments
